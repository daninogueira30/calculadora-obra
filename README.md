# Calculadora de Materiais de Obra

Aplicação web responsiva que estima a quantidade de materiais de construção a partir das medidas informadas. O projeto une minha formação em Engenharia Civil com desenvolvimento front-end.

🔗 **Acesse:** [link do GitHub Pages]

## Funcionalidades

- **Concreto:** calcula o volume e a quantidade de cimento, areia e brita (traço 1:2:3)
- **Tijolos e blocos:** calcula quantas peças são necessárias para uma parede, descontando portas e janelas
- **Argamassa de reboco:** calcula o volume de argamassa pela área e espessura do reboco

Todos os cálculos incluem 10% de perda.

## Tecnologias

- HTML5
- CSS3 (Grid, Flexbox e variáveis CSS)
- JavaScript (manipulação do DOM e eventos)

## Como executar

Basta abrir o arquivo `index.html` no navegador. Não é preciso instalar nada.
